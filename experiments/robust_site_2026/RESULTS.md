# ВОСТОК-612. Оценка конфигураций при неполных данных о площадках

## Исходные данные

В книге «Выбор места.xlsx» найдена 21 именованная площадка. Все 126 входных баллов и 21 итоговая сумма совпадают с `data/sites.csv` после сопоставления по названию. Книга подтверждает происхождение таблицы, а шкала представляет исходные порядковые оценки проекта. Сводный документ Конгресса содержит инженерное обоснование предварительного выбора Большого Камня и СВБР-100. Книга «Выбор реактора.xlsx» содержит характеристики технологий. Суточный график РДУ Якутии содержит 24 значения на сезон и описывает нагрузку энергосистемы в целом. Его использование в качестве спроса каждой отдельной площадки исказило бы расчёт. Таблицы по Южно-Сахалинску содержат расчётные оценки с отдельными статьями затрат. Для включения их в сравнительный расчёт требуется согласовать состав CAPEX, денежного OPEX и амортизации с текущими профилями.

Эксперимент использует 276 конфигураций, прошедших числовой фильтр мощности в обоих сохранённых профилях `legacy_21x26` и `updated_21x26`. Экономические параметры этих профилей сценарные. Набор кандидатов, веса, спрос и правила составления рейтинга фиксированы. Изменяются только принадлежность к одному из двух профилей и значения пропущенных критериев площадок.

## Модель

Балл конфигурации i в профиле p выражается как S(p,i) = b(p,i) + a(sᵢ). Слагаемое b включает экономику, соответствие мощности спросу и вклад постоянной части расчётного риска. Слагаемое a зависит от шести порядковых оценок площадки и их влияния на расчётный риск через логистику. Один и тот же a используется всеми реакторами и вариантами числа модулей на площадке. Неизвестная оценка варьируется от 1 до 5 независимо от других неизвестных оценок.

Для каждого кандидата рассчитывается максимальная потеря балла относительно лучшей альтернативы по обоим профилям и всем допустимым заполнениям. У конкурента с той же площадки общий член a сокращается, поэтому разница равна b(p,j) − b(p,i). Для конкурента с другой площадки максимум достигается при верхней границе эффекта его площадки и нижней границе эффекта оцениваемой площадки. Максимум по всем конкурентам и профилям даёт точную границу потери в этой постановке. Модель рекомендует одну из конфигураций с минимальной границей, когда она укладывается в заданный допуск, и воздерживается, когда допуск превышен. Баллы нормированы по шкале 0–100. Один балл принят как исследовательский допуск. В сводке также есть результаты для 0, 0,5, 2 и 5 баллов.

Консервативный контроль использует отдельный интервал на каждую конфигурацию. Он допускает разные значения одной оценки площадки для разных конфигураций, из-за чего граница потери может быть шире. В дополнительных сравнениях среднее по каждому столбцу и KNN с тремя соседями восстанавливают скрытые значения. Затем выбирается кандидат с минимальной максимальной потерей по двум экономическим профилям на заполненной матрице. Для этих двух методов доля рекомендаций рассчитана с проверкой той же точной границей, чтобы сравнивать допуск на одинаковых условиях.

## Эксперимент

На каждой комбинации механизма и доли пропусков выполнено 300 повторов. Всего 1800 общих масок и 7200 решений. Скрывалось 13, 25 или 38 из 126 баллов. Использовались равномерное сокрытие ячеек и сокрытие целыми строками площадок с частичной последней строкой. Исходные баллы использовались после выбора кандидата для вычисления потери на полной матрице. Эталон относится к тем же двум сценарным профилям.

| Маска | Пропуски | Рекомендации в пределах 1 балла, независимые → общие интервалы | Совпадение с выбором при полной матрице, независимые → общие интервалы |
|---|---:|---:|---:|
| Равномерная | ≈10% | 42,0 → 52,0% | 76,0 → 86,0% |
| Равномерная | ≈20% | 12,3 → 16,7% | 64,0 → 71,7% |
| Равномерная | ≈30% | 3,7 → 3,7% | 54,7 → 59,3% |
| Целые площадки | ≈10% | 16,0 → 16,0% | 88,0 → 88,0% |
| Целые площадки | ≈20% | 2,0 → 2,3% | 78,7 → 78,7% |
| Целые площадки | ≈30% | 0 → 0% | 62,3 → 62,3% |

При ≈10% равномерных пропусков средняя верхняя граница потери снизилась с 2,21 до 1,76 балла. Рекомендацию в пределах одного балла получили ещё 30 из 300 масок. При сокрытии целых площадок обе интервальные модели во всех 900 прогонах выбрали одни и те же конфигурации. Эффект учёта общих признаков зависит от расположения пропусков.

KNN чаще воспроизводил выбор по полной матрице при ≈10% и ≈20% равномерных пропусков (92,0% и 82,0%). После проверки границей потери доля рекомендаций в пределах одного балла совпала с результатом модели с общими эффектами (52,0% и 16,7%). При ≈30% равномерных пропусков в трёх изолированных подходах — KNN, среднее и общие интервалы — доля рекомендаций составила 3,7%. Повторности характеризуют распределение искусственных масок на одной базе. Результаты для реальных механизмов пропусков и новых площадок остаются открытыми.

## Текст для статьи

> Для предварительного сравнения конфигураций АСММ предложена модель интервальной оценки, в которой неизвестные характеристики площадки являются общими для всех рассматриваемых на ней реакторных вариантов. Получено точное выражение для максимальной потери балла при двух сценарных профилях затрат. При равномерном сокрытии около 10% исходных оценок учёт общей неопределённости увеличил долю рекомендаций, удовлетворяющих допуску в один балл, с 42,0 до 52,0% по сравнению с независимыми интервалами конфигураций. При сокрытии целых строк площадок сопоставимый эффект не наблюдался. Таким образом, влияние учёта структуры данных зависит от механизма возникновения пропусков.

Минимаксное сожаление — известный критерий. Кандидат на прикладной вклад состоит в точном учёте общих характеристик при совместном выборе площадки, технологии и числа модулей, а также в количественной оценке эффекта при разных структурах пропусков. Формулировка не предполагает приоритета в литературе. Близкие работы: [Averbakh, 2001, интервальная неопределённость и минимаксное сожаление](https://www.sciencedirect.com/science/article/pii/S0167637700000250) и [Wang, Boutilier, 2003, последовательное уточнение предпочтений по минимаксному сожалению](https://ijcai.org/proceedings/2003/46).

В дальнейшем можно проверить активное уточнение характеристик, последовательно раскрывая один известный контрольный балл. Главная величина для сравнения — число раскрытий, необходимое для достижения заданного допуска. Политика выбора по снижению максимальной потери и случайный запрос должны работать на одинаковых масках и при одинаковом бюджете. Этот эксперимент в текущий запуск не входит.

## Воспроизведение

Из корня репозитория:

```sh
python3 scripts/robust_site_evaluation.py --repeats 300
python3 scripts/robust_site_evaluation.py --site-scores path/to/site_scores.csv --tolerance 1 --out path/to/results
```

В пользовательской таблице нужны столбцы `site,deficit,oyat,logistics,industry,economy,geo_climate` и те же 21 площадка; пустая ячейка означает неизвестную оценку. Код проверяет совпадение состава профилей и восстанавливает исходные баллы в пределах точности их округления. Результаты приведены в `summary.csv`, повторы сохранены в `trials.csv`. Полный рейтинг при известных оценках находится в `ranking.csv`. В обоих профилях максимальный балл имеет конфигурация «Большой Камень / LFR-AS-200 / 1». Это результат двух модельных сценариев и фиксированных весов. Для исходного выбора «Большой Камень / СВБР-100 / 2» максимальная потеря балла приведена в том же файле.
